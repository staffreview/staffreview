# Staff Document

Create a short markdown lesson under `.staffreview/docs/` from review feedback
and its surrounding code context.

## Load

- For source collection, filename guidance, and the markdown schema, read
  `references/document-format.md`.
- If the user only asks what this skill does, do not load references.

## Rules

- Pick a filename that names the lesson, not the source comment.
- Keep entries to roughly one screenful.
- Do not include reviewer or author names.
- Do not overwrite an existing docs file.
